# The Proposal — Moment Template Demo

An English demo for the **moment** template: one afternoon, framed by time.

## Why this demo exists

Two things make moment Relics different, and both are demonstrated here:

1. **Scene before meaning.** Slow motion first — what was visible, audible,
   physical — and only then what it came to mean.

2. **Disagreement preserved.** The two accounts disagree about whether anyone
   cried. The Relic keeps both and labels it unresolved rather than picking one.

## Try it

```text
"Replay it."
"Who said it first?"
"How did you tell it five years later?"
```

## Build your own

```bash
python3 scripts/relic_writer.py --data photos.json --template moment --slug our-day
```
