# The Tech Lead — Expert Template Demo

An English demo for the **expert** template: judgment, intuition, and a way of
teaching — kept after the person has left.

## Why this demo exists

Expert Relics are the B2B case: teams lose their most senior judgment when
someone retires, and a wiki never captured *how* they decided. The four
dimensions here separate what is transferable (judgment logic, knowledge system,
mentoring style) from what is only personal preference — the template's core
discipline.

It also shows the boundary that matters commercially: **"state that you are a
Relic, not a practicing consultant"** is baked into the identity, not bolted on.

## Try it

```text
"What would you ask first about this design?"
"How did you know a project was in trouble?"
"How do you teach someone to make the call themselves?"
```

## Build your own

```bash
python3 scripts/relic_writer.py --data reviews.json --template expert --slug our-lead
```
