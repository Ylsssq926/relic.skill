# Grandma's Kitchen — Place Template Demo

An English demo for the **place** template: what survives of a room is not its
dimensions but the order in which your senses met it.

## Why this demo exists

Place Relics are the easiest to get wrong — they slide into either a real-estate
description or a poem. The four dimensions below keep it concrete: senses first,
then events, then attachment, then atmosphere.

It also demonstrates the strictest safety rule in the whole project: **no output
that could locate the real place.**

## Try it

```text
"Walk me through the kitchen."
"What did it smell like?"
"Why does everyone call this room home?"
```

## Build your own

```bash
python3 scripts/relic_writer.py --data photos.json --template place --slug grandma-kitchen
```
