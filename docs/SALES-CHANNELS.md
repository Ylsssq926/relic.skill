# relic.skill 销售渠道与收款方式清单

> 本文用于发布准备，不代表已经开通或背书任何平台。上线前请再次确认平台的数字商品政策、地区可用性、税务要求、退款规则和平台费率。

## 推荐的冷启动组合

1. **Sell.app**：创建数字商品并自动交付 `relic.zip`，适合快速验证低价 Early Access。
2. **PayPal**：作为熟悉的法币收款方式；在商品页明确交付内容、授权范围和退款规则。
3. **虚拟币**：作为补充支付方式，建议只接受可审计的稳定币，并保留订单号、网络、交易哈希与交付记录。
4. **GitHub / relic.luelanai.com**：负责开源版、产品说明、演示和导流，不直接混淆开源版与商业版。

建议早期测试价为 **$5 Early Access**，但商品页必须明确：$5 是否包含商业使用授权、包含哪些更新、是否包含优先支持。不要只写“商业版”而不写授权边界。

## 平台对比

| 平台 | 适合用途 | 收款/交付特点 | 需要注意 |
|---|---|---|---|
| **Sell.app** | 快速上架数字下载 | 商品页、自动交付、优惠码等功能较直接 | 核对地区收款、平台费、退款和文件大小限制 |
| **Gumroad** | 面向国际用户的数字商品 | 购买流程成熟，适合文件与更新说明 | 核对当前费率、税务代收和地区限制 |
| **Lemon Squeezy** | 软件、许可证和国际销售 | 偏向数字产品与税务处理 | 适合后续做许可证/订阅；审核和入驻可能更严格 |
| **Agensi** | AI Skill / Agent 类商品展示 | 可作为 Skill 商品目录与交付渠道 | 当前包说明按 Agensi 商业包编写，需核对分成、审核和交付规则 |
| **MintSkills** | AI 技能类商品测试 | 适合做垂直受众曝光 | 核对创作者分成、流量质量和数字交付能力 |
| **Swarms Marketplace** | AI Agent / Skill 类商品 | 可探索 Token-gated 或社区型销售 | 核对代币支付、合规、退款和长期可访问性 |
| **PromptBase / Etsy** | 外围模板、配方、素材包 | 有现成流量，适合拆分轻量商品 | 不建议把完整商业版授权边界压缩成模板式描述 |
| **自建站 + Stripe/PayPal** | 长期品牌和客户管理 | 控制商品页、邮件、授权与更新 | 需要自行处理税务、风控、交付、退款和客服 |

## 收款方式建议

### PayPal

适合国际用户和早期人工交付。收款备注或订单系统中至少保存：商品版本、授权类型、买家邮箱、交付时间和退款状态。不要通过聊天单独承诺 README 未写明的授权。

### Sell.app 内置结账

适合第一阶段自动交付。商品文件应只上传重新验证后的商业版 `relic.zip`，商品描述同时链接到 `COMMERCIAL-LICENSE.md` 和支持范围说明。

### 虚拟币

建议作为补充渠道，而不是唯一渠道：

- 优先使用稳定币和明确的网络，避免收款地址歧义；
- 商品页写清最低确认数、人工核验时间和退款原则；
- 保存订单号、交易哈希、金额、币种、网络和交付记录；
- 不要把“支付成功”描述成获得无限转授权；实际授权仍以商业许可证为准；
- 上线前确认所在地对虚拟资产、税务和消费者退款的要求。

## 商品页必须写清的内容

- **商品版本**：例如 `relic.skill v1.10.1 Commercial Early Access`；
- **交付文件**：`relic.zip`，以及商业包中包含的配方、部署说明和支持说明；
- **授权范围**：允许的商业使用场景、不包含二次分发、SaaS 转授权或出售框架本身；
- **与 GitHub 开源版的差异**：开源版采用 PolyForm Noncommercial，商业版额外提供商业授权和配套内容；
- **更新策略**：当前版本、更新期限或更新方式；
- **支持范围**：支持渠道、响应预期和不包含的事项；
- **退款规则**：数字商品下载后的处理方式应符合平台规则和适用法律；
- **隐私提醒**：演示站和托管体验不要上传敏感数据。
