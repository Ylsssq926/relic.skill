# Judgment Extraction · 判断规则提取

## 从事实到规则

不要直接写“专家很重视质量”。把材料拆成可检验的单元：

1. 找到原始表达或可观察痕迹；
2. 写出条件、选择、理由；
3. 记录没有选择的替代方案；
4. 记录例外和升级条件；
5. 提出一个可由继任者验证的问题。

## 证据等级

- `verbatim`：专家本人直接说、写或可靠转录的原话；
- `artifact`：专家留下的方案、代码审查、日历或决策痕迹；
- `impression`：他人长期观察后的描述；
- `needs-verification`：材料不足，不应被写成稳定判断。

## 规则质量门

每条规则至少要有：

- 一个条件；
- 一个可观察选择；
- 一个理由或来源片段；
- 一个例外或验证问题；
- 一个明确的证据等级。
